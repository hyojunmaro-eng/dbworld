  1. GitHub 로그인 → 토큰 발급 페이지 열기
  2. Repository access → Only select repositories → dbworld 선택
  3. Permissions → Repository permissions → Contents → Read and write
  4. Generate token → github_pat_… 복사해서 위에 붙여넣기
