DB월드 홈페이지 관리

저장하면 GitHub에 기록되고, 1~2분 안에 사이트에 자동 반영됩니다. 날짜 기준으로 자동 정렬되므로 중간 날짜로 저장하면 목록 중간에 들어갑니다.

⚠ 지금 토큰으로는 저장할 수 없습니다 (읽기 전용 토큰)

목록은 보이지만 글·팝업 저장은 GitHub가 거부합니다. 토큰 설정만 아래처럼 바꾸면 토큰을 다시 입력할 필요 없이 바로 저장됩니다.

  1. GitHub 토큰 목록 열기 → 이 관리자에 쓰는 토큰 클릭 → Edit
  2. Repository access → Only select repositories → dbworld 선택 (기본값 "Public repositories (read-only)"면 저장 불가)
  3. Permissions → Contents → Read and write (추가할 때 기본값이 Read-only)
  4. 맨 아래 Update → 이 화면에서

토큰이 없다면 (관리자 1회 발급 후 협업자와 공유):

  1. GitHub 로그인 → 토큰 발급 페이지 열기
  2. Repository access → Only select repositories → dbworld 선택 (기본값 "Public repositories"로 두면 저장 불가)
  3. Permissions → Contents → Read and write (추가할 때 기본값이 Read-only — 꼭 바꾸기)
  4. Generate token → github_pat_… 복사해서 위에 붙여넣기

새 글 쓰기

    PDF·이미지·한글문서 등 첨부 가능 (파일당 15MB 이하 권장). 업로드하면 목록에 추가되고, 저장 시 글에 연결됩니다.

    팝업 관리

    팝업은 지정한 페이지(기본: 메인 화면)의 화면 중앙에 크게 표시됩니다(A4 문서는 화면 높이에 맞춤). 한 페이지에 여러 개가 걸리면 한 창에서 ‹ 1 / 3 › 처럼 넘겨 보게 됩니다. 게시 기간은 방문자 화면에서 날짜 기준으로 자동 적용되므로, 예정 팝업은 시작일에 자동으로 뜨고 종료일이 지나면 자동으로 내려갑니다.
