    팝업 관리

    팝업은 지정한 페이지(기본: 메인 화면)의 화면 중앙에 크게 표시됩니다(A4 문서는 화면 높이에 맞춤). 한 페이지에 여러 개가 걸리면 한 창에서 ‹ 1 / 3 › 처럼 넘겨 보게 됩니다. 게시 기간은 방문자 화면에서 날짜 기준으로 자동 적용됩니다.

      사용방법

      홈페이지 홍보센터 › 공지사항 · 뉴스·보도에 글을 올리고 고치는 방법입니다.

      0접속하기

      • 관리자 비밀번호를 입력해 로그인합니다. 서버가 다시 시작되면 다시 로그인해야 합니다.
      • 비밀번호는 서버 담당자가 관리합니다(ADMIN_PASSWORD). 외부에 공유하지 마세요.

      1새 글 쓰기

      1. 목록 화면에서 [＋ 새 글 쓰기]를 누릅니다.
      2. 날짜 — 게시일입니다. 목록은 날짜순으로 자동 정렬되고 번호도 자동으로 매겨집니다. 지난 날짜로 쓰면 목록 중간에 들어갑니다.
      3. 분류 — 공지사항 또는 뉴스·보도.
      4. 목록 상단 고정 — 체크하면 날짜와 상관없이 맨 위에 고정됩니다. 중요한 공고에만 쓰세요.
      5. 제목 — 필수. 영문 제목·본문은 비워 두면 영문 페이지에도 한국어가 그대로 나옵니다.
      6. 본문을 쓰고(아래 2번 참고) 필요하면 첨부파일을 올린 뒤(3번) [저장 및 사이트 반영]을 누릅니다.

      3첨부파일

      • [파일 선택]으로 고르면 바로 업로드되어 목록에 추가됩니다. 여러 개를 한 번에 골라도 됩니다.
      • “업로드 완료” 메시지를 확인한 뒤 저장하세요. 업로드 중에는 저장이 되지 않습니다.
      • 방문자가 바로 열어볼 수 있는 PDF를 권장합니다. 한글(HWP) 파일은 한글 프로그램이 있어야 열립니다.
      • 파일당 25MB 이하로 올려 주세요.
      • 파일 이름이 그대로 다운로드 이름이 되니, 올리기 전에 알아보기 쉬운 이름으로 바꿔 두세요. 예) 2026_임시주주총회_소집공고.pdf
      • [빼기]는 글에서만 빠집니다.

      4수정 · 삭제

      • 목록에서 [수정] → 고친 뒤 [저장 및 사이트 반영]. 날짜를 바꾸면 목록 위치도 바뀝니다.
      • [이 글 삭제]는 되돌릴 수 없습니다.

      5반영 확인

      저장하면 바로 사이트에 반영됩니다. 해당 페이지를 새로고침(F5)해서 확인하세요.

      영문 페이지에 한국어가 나와요
      영문 제목·본문을 비워 두면 한국어가 그대로 나옵니다. 영문이 필요하면 해당 칸을 채워 다시 저장하세요.
      빨간 오류 메시지가 떠요

      홈페이지에 뜨는 안내 팝업(공고문·행사 안내 등)을 올리는 방법입니다.

      1공고문을 팝업 이미지(PNG)로 만들기

      방법 ① 화면 캡처 — 가장 쉽고, 한글·워드·PDF 모두 가능

      1. 문서를 열고 한 페이지가 화면에 꽉 차도록 확대합니다 (보통 100~150%).
      2. 키보드 Win + Shift + S → 화면이 어두워지면 문서의 흰 종이 부분만 사각형으로 드래그합니다.
      3. 오른쪽 아래 알림을 클릭해 캡처 도구가 열리면 Ctrl + S → PNG로 저장합니다.

      방법 ② 한글(HWP)에서 바로 저장

      1. [파일] → [다른 이름으로 저장하기] → 파일 형식에서 PNG 이미지를 고릅니다.
      2. 쪽(페이지)마다 그림 파일이 하나씩 만들어집니다. 필요한 쪽을 올리세요.

      PDF는 방법 ①로 캡처하면 됩니다. Adobe Acrobat(유료)이 있다면 [파일] → [내보내기] → [이미지] → PNG도 가능합니다.

      선명하게 만드는 요령
      · 크게 확대해서 캡처할수록 글자가 선명합니다. 가로 1000px 이상이면 충분합니다.
      · 문서 바깥의 회색 배경·스크롤바·메뉴가 들어가지 않게 종이 부분만 잡아 주세요.
      · 용량은 신경 쓰지 않아도 됩니다. 올릴 때 글자가 선명한 크기로 자동으로 줄여서 올라갑니다.
      · JPG·PNG·WEBP·GIF를 쓸 수 있습니다. 아이폰 사진(HEIC)은 JPG로 바꿔서 올려 주세요.

      2새 팝업 등록

      1. [팝업 관리] → [＋ 새 팝업]을 누릅니다.
      2. 팝업 이미지를 고릅니다. 썸네일과 크기 안내가 나오면 준비 완료입니다. (이미지는 저장할 때 함께 올라갑니다)
      3. 노출 여부 — 체크를 끄면 저장만 되고 사이트에는 뜨지 않습니다. 미리 만들어 둘 때 쓰세요.
      4. 노출 기기 — 전체 / PC만 / 모바일만.
      5. 노출 페이지 — 기본은 메인 화면입니다. 검색창에 “공지”, “재무”처럼 입력하고 목록에서 눌러 추가합니다(여러 개 가능). 전체 페이지를 고르면 사이트 모든 화면에 뜹니다. 칩의 ×로 뺍니다.
      6. 게시기간 — [항상 노출]을 끄고 시작일~종료일을 정합니다. 시작일 0시부터 종료일 밤 12시까지 뜨고, 기간이 끝나면 자동으로 내려갑니다. 시작일이나 종료일 한쪽만 정해도 됩니다.
      7. 팝업 링크(선택) — 팝업을 누르면 이동할 주소입니다. 외부 사이트는 https://…, 우리 사이트 안 페이지는 /ko/news/처럼 경로만 적으면 도메인이 바뀌어도 그대로 동작합니다.
      8. [미리보기]로 모양을 확인하고 [저장 및 사이트 반영]을 누릅니다.

      3목록 보는 법

      게시 중지금 사이트에 뜨고 있는 팝업
      게시 예정시작일이 아직 안 된 팝업 — 시작일에 자동으로 뜹니다
      게시 중지기간이 끝났거나 노출을 끈 팝업 — 데이터는 계속 보관되어 다시 켜서 쓸 수 있습니다

      게시만 멈추려면 삭제하지 말고 [수정]에서 노출 활성화를 끄세요. 삭제는 되돌릴 수 없습니다.

      4여러 개를 띄울 때 · 순서 바꾸기

      • 같은 페이지에 팝업이 여러 개 걸리면 한 창에서 ‹ 1 / 3 › 으로 넘겨 보게 됩니다. (키보드 ←/→, 휴대폰은 좌우로 밀기)
      • 카드 왼쪽 위 번호가 보이는 순서입니다. ◀ 앞으로 / 뒤로 ▶ 버튼이나 카드를 끌어서 바꾼 뒤, 위에 나타나는 [순서 저장 및 사이트 반영]을 누르세요.
      • 새로 등록한 팝업은 맨 앞(1번)에 들어갑니다.

      5방문자에게 보이는 모습

      • 팝업 크기는 이미지에 맞춰 자동으로 정해집니다. A4 공고문은 화면 높이에 맞춰 크게 보이고, 가로는 최대 960px입니다.
      • 오늘 하루 보지 않기 — 그 PC(휴대폰)에서는 오늘 하루 다시 뜨지 않습니다. 함께 뜬 팝업 모두에 적용됩니다.
      • × — 창만 닫습니다. 새로고침하면 다시 뜹니다.
      • 영문 페이지에도 같은 팝업이 뜨고, 버튼 글자만 영어로 바뀝니다.

      6수정 · 삭제 · 확인

      • [수정]에서 이미지를 바꿀 수 있습니다. 쓰지 않게 된 옛 이미지는 자동으로 정리됩니다.
      • [이 팝업 삭제]는 이미지까지 함께 지워지며 되돌릴 수 없습니다.
      • 반영: 저장하면 바로 사이트에 반영됩니다.
      • “오늘 하루 보지 않기”를 눌렀던 PC에서는 오늘 팝업이 안 뜹니다. 확인할 때는 시크릿 창(Ctrl + Shift + N)으로 열어 보세요.
